# SeisWave UI 重新设计方案

## 根子问题（用户反馈）

当前 UI 的根本缺陷：
1. **布局混乱**：元素遮挡、显示不全、长宽畸形
2. **左侧参数面板太窄**：360px 在复杂参数下仍然拥挤
3. **组件耦合严重**：God Class（GeneratorPanel 562行→173行仍然做太多事）
4. **没有响应式设计**：窗口缩放时元素变形
5. **缺乏视觉层次**：所有组件看起来一样重要，没有主次

## 新设计原则

### 1. 三栏响应式布局
```
┌─────────────────────────────────────────────────┐
│  顶部工具栏 (Toolbar)                            │
├──────────┬────────────────────────┬──────────────┤
│          │                        │              │
│  左栏    │      中间主区域        │   右栏      │
│  参数    │      (绘图+结果)       │   信息      │
│  (固定   │                        │   (动态)     │
│   宽度)  │                        │              │
│          │                        │              │
├──────────┴────────────────────────┴──────────────┤
│  底部状态栏                                      │
└─────────────────────────────────────────────────┘
```

- **左栏**：320px 固定，可折叠，QScrollArea 保证不溢出
- **中间**：弹性拉伸，最小 600px
- **右栏**：280px 固定，可折叠，显示结果摘要/脉冲参数

### 2. 参数分组卡片化
- 每组参数用 `QGroupBox` 包裹，但有**统一间距**和**清晰标题**
- 默认只展开当前需要的组（如 NFP 时展开震源参数 + 断层参数）
- 其他组折叠（点击标题展开）

### 3. 关键组件职责分离

| 文件 | 职责 | 行数目标 |
|------|------|---------|
| `generator_panel.py` | 仅做三栏布局组合 | ~60 |
| `left_panel.py` | 参数输入 + 类型切换 | ~150 |
| `center_panel.py` | 绘图区 + 谱对比 + 时程 | ~120 |
| `right_panel.py` | 结果摘要 + NFP脉冲参数 | ~100 |
| `bottom_bar.py` | 状态栏 + 进度 | ~50 |
| `param_cards.py` | 参数卡片组件（可复用） | ~200 |

### 4. 样式规范
- 统一 QSS 主题文件：`seiswave/gui/styles/theme.qss`
- 颜色变量化（primary/secondary/accent/warning/success）
- 字体层级：标题 14px bold，标签 12px，值 12px monospace
- 间距规范：组件间 12px，组内 8px

### 5. NFP 专属 UI
- 选择 NFP 时，右栏自动显示脉冲参数卡片
- 脉冲速度时程用**独立小图**显示在右栏
- Baker 识别结果用**进度条样式**显示置信度

## 实现计划

1. 先写 `theme.qss` 统一样式
2. 创建 `param_cards.py` 参数卡片组件
3. 创建 `left_panel.py` / `center_panel.py` / `right_panel.py`
4. 重写 `generator_panel.py` 只做布局组合
5. 更新 `main_window.py` 调整窗口默认大小（1200x800）
6. 测试：启动 GUI，验证三类地震动各生成一次，无遮挡

## 验收标准
- [ ] 窗口默认 1200x800，可缩放到 900x600 不遮挡
- [ ] 左栏参数区有滚动条，无溢出
- [ ] 中间绘图区宽度 ≥ 500px，谱线清晰可见
- [ ] 右栏结果区在一般/FF/NF 时折叠，NFP 时展开
- [ ] 所有 QGroupBox 标题统一加粗，间距一致
- [ ] 三类地震动各生成一次，界面不闪退
- [ ] 104 个回归测试全绿
