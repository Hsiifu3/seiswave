# [Feature-001] SeisWave 特殊地震动生成功能 — 需求规格

## 概述

为 SeisWave 增加三种特殊地震动的人工生成功能：Far-Field (FF)、Near-Field No-Pulse (NF)、Near-Field Pulse (NFP)。

## 背景 / 目标

SeisWave 目前只能生成"一般人工波"（基于目标谱的迭代匹配）。但 FEMA P695 / ATC-63 规范要求对结构进行三类地震动分别评估：

1. **Far-Field (FF)** — 远场地震动，用于常规抗震评估
2. **Near-Field No-Pulse (NF)** — 近场无脉冲，用于近场非脉冲场景
3. **Near-Field Pulse (NFP)** — 近场脉冲，用于脉冲敏感结构评估

目标是在现有谱匹配框架上扩展，支持这三类地震动的参数化生成。

## 用户故事

### US-1: 远场地震动生成
作为地震工程师，我希望输入震级、距离、场地条件，生成符合远场特征的地震动时程，以便进行常规抗震分析。

**验收标准**：
- AC-1.1: 输入 Mw, R, Vs30, 输出加速度时程
- AC-1.2: 生成结果的反应谱与目标谱误差 < 5%
- AC-1.3: 速度时程无明显脉冲特征（Baker 2007 脉冲识别为 false）
- AC-1.4: 持时特征符合远场经验（D₅₋₉₅ ≈ 25-40s for M7, R50km）

### US-2: 近场无脉冲地震动生成
作为地震工程师，我希望输入近场参数但指定"无脉冲"，生成符合近场无脉冲特征的地震动，以便评估非脉冲近场效应。

**验收标准**：
- AC-2.1: 输入 Mw, R < 10km, 输出加速度时程
- AC-2.2: 高频成分相对丰富，PGA/PGV > 1.2 g/(m/s)
- AC-2.3: 速度时程无脉冲特征
- AC-2.4: 持时中等（15-40s）

### US-3: 近场脉冲地震动生成
作为地震工程师，我希望输入近场参数，生成包含显著速度脉冲的地震动，以便评估脉冲敏感结构（如隔震结构、长周期结构）的响应。

**验收标准**：
- AC-3.1: 输入 Mw, R, 断层类型, 输出含脉冲的加速度时程
- AC-3.2: 速度时程显示显著脉冲（PGV > 100 cm/s）
- AC-3.3: 脉冲周期 Tp 符合震级经验关系（ln(Tp) ≈ -6.68 + 1.15 Mw）
- AC-3.4: Baker (2007) 脉冲识别指标 > 0.85（高置信度脉冲）
- AC-3.5: 总能量在脉冲周期附近集中（频谱峰值显著）

### US-4: 统一接口
作为用户，我希望通过统一接口选择地震动类型并生成，无需关心底层算法差异。

**验收标准**：
- AC-4.1: `WaveGenerator.generate(type="FF|NF|NFP", **params)` 统一入口
- AC-4.2: GUI 下拉菜单选择地震动类型
- AC-4.3: 每种类型有预设参数模板
- AC-4.4: 生成后自动显示反应谱、速度时程、脉冲识别结果（NFP）

## 非功能需求
- 性能：单次生成时间 < 5s（现有谱匹配 + 脉冲叠加）
- 精度：反应谱匹配误差 < 5%
- 兼容性：与现有 SeisWave v2.0 数据格式兼容
- 可维护性：新增模块与现有代码解耦，独立测试

## 约束条件
- 必须复用现有谱匹配引擎（EQSignal 方法）
- 脉冲模型基于 Mavroeidis & Papageorgiou (2003) 解析模型
- 保持 Fortran/C 加速路径（性能要求）
- Python 回退路径必须可用

## 超出范围
- 真实地震动记录选择（从 PEER NGA 下载）
- 双向地震动生成（先实现单向）
- 断层破裂过程模拟（用简化脉冲模型）
- 场地效应详细模拟（用简化 Vs30 调整）
