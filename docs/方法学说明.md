## 1. 目标谱

SeisWave 的目标谱有三个来源，统一由 `TargetSpectrumService` 管理：

### 1.1 规范设计谱（GB 50011 / GB/T 51408）

**GB 50011-2010 地震影响系数曲线**（四段式，`core/code_spec.py::gb50011`），**仅定义于 0–6 s**，
超出 6 s 不外推（目标谱周期在 `set_code` 中截断至 ≤ 6 s）：

| 段 | 周期范围 | 表达式 |
|---|---|---|
| 上升段 | `T < 0.1` | `α = 0.45·α_max + (T/0.1)·(η₂·α_max − 0.45·α_max)` |
| 平台段 | `0.1 ≤ T ≤ Tg` | `α = η₂·α_max` |
| 曲线下降段 | `Tg < T ≤ 5Tg` | `α = (Tg/T)^γ · η₂ · α_max` |
| 直线下降段 | `5Tg < T ≤ 6.0` | `α = [η₂·0.2^γ − η₁·(T−5Tg)]·α_max` |

阻尼调整系数（GB 50011 §5.1.5）：

```
γ  = 0.9 + (0.05 − ζ)/(0.3 + 6ζ)
η₁ = 0.02 + (0.05 − ζ)/(4 + 32ζ)          （< 0 时取 0）
η₂ = 1.0 + (0.05 − ζ)/(0.08 + 1.6ζ)        （< 0.55 时取 0.55）
```
ζ = 0.05 时 γ = 0.9、η₁ = 0.02、η₂ = 1.0。

- **特征周期 Tg**：查 GB 50011 表 5.1.4-2（设计地震分组 × 场地类别 I0/I1/II/III/IV）。
- **α_max**：查 GB 50011 表 5.1.4-1。**规范仅列"多遇地震"与"罕遇地震"两档**；
  "设防地震（中震）"档为近似值（≈多遇×2.8），在 UI 中明确标注"近似·规范未列表"。
  **选波/时程分析的标准目标谱为多遇地震（§5.1.2），故对话框默认多遇。**

**GB/T 51408-2015 隔震设计谱**（`core/code_spec.py`，`isolation=True`）：取消第四段，
曲线下降段延伸至 6 s。

### 1.2 中国地震动 GMPE（第五代区划，仅用于 FF/NF/NFP 情景谱）

`core/gmpe.py::ChinaGMPEAdapter`，基于 GB 18306-2015 第五代区划图衰减关系（俞言祥模型）：

```
lg Y = A + B·M + C·lg(R + D·e^(E·M))
```
按 4 个分区（东部强震/中强/新疆/青藏）× 椭圆长短轴提供系数；aE→α_max（=2.5·aE/g）、
Tg（=2π·nE/aE）。**该谱定位为"情景/危险性谱"，非规范设计谱**，仅作为 FF/NF/NFP 的可选谱源。

### 1.3 自定义谱

两列 (周期, Sa) 的 CSV/TXT 文件，或直接传入数组。

## 2. 选波

`core/selector.py::WaveSelector`，**与结构周期绑定**（GB 50011 §5.1.2"在结构主要振型
周期点上与规范谱统计相符"）：

- `SelectionConfig.T_main = [T₁, T₂, T₃]`：结构主周期。
- **缩放**：`_optimal_scale` 对主周期附近加权，确保缩放后主周期点匹配最优。
- **筛选**：按各主周期点偏差 ≤ `spectral_tol` 剔除。
- **持时**：有效持时 ≥ `duration_factor × max(T_main)`。
- **匹配误差**：仅取 T ≥ 0.1 s 部分的 RMSE，避免短周期噪声污染。

候选库支持 PEER 目录（`peer_db`）与已导入信号池。

## 3. 人工波谱匹配

`core/spectral_match.py::match_to_target`，**Al Atik & Abrahamson (2010) 小波时域调整法**：

- 带符号修正量 `dR = sign(SPA) − SPA/target`；
- 反应谱灵敏度矩阵 `M`（经 FFT 高效构造），Tikhonov 正则化求解调整系数 `α`；
- **回溯线搜索**（backtracking line-search）保证每步反应谱误差单调下降；
- 反应谱用 Newmark-β 法（`core/spectrum.py`）。

该实现从生成器抽出为独立模块，抽出前后数值逐位一致（`np.allclose`，golden 回归）。

## 4. 特殊地震动 FF / NF / NFP

近场效应概念源自美标/研究体系（FEMA P695、NGA、Somerville 方向性），
中国 GB 50011 仅提供近断层放大系数。SeisWave 据此做有依据的映射。

### 4.1 近断层放大系数（GB 50011 §3.10 / 附录 L）

| 距发震断裂 R | 系数 |
|---|---|
| < 5 km | ×1.5 |
| 5–10 km | ×1.25 |
| > 10 km | ×1.0 |
| 远场 FF | ×1.0 |

### 4.2 三型定义

| 类型 | 目标谱 | 脉冲 |
|---|---|---|
| **FF**（远场） | 设计谱 × 1.0 | 无 |
| **NF**（近场无脉冲） | 设计谱 × 近场系数 | 无 |
| **NFP**（近场脉冲） | 设计谱 × 近场系数 | Mavroeidis-Papageorgiou 脉冲 + 残余 |

> **说明**：NF 与 FF 的差异**仅为谱幅值乘子**（近场系数），波形形状相同；时程图各自
> 自动缩放纵轴时看不出差别属正常，需对比 PGA 数值。NFP 的脉冲在**速度时程**中最明显，
> 且目标谱越强（罕遇/情景谱）脉冲越显著；多遇/小震弱谱下脉冲被残余安全缩放压低甚至消失。

### 4.3 脉冲模型（Mavroeidis & Papageorgiou 2003）

`core/pulse.py`，**完整 MP(2003) 解析式**：

**脉冲周期 Tp**（MP 2003 原式）：
```
log10(Tp) = −2.9 + 0.5·Mw          # Tp 单位 s
```

**速度脉冲**（MP 2003 完整式，含振荡参数 γ）：
```
v(t) = (A/2)·[1 + cos(2π(t−t₀)/(γ·Tp))]·cos(2π(t−t₀)/Tp + φ),   |t−t₀| ≤ γ·Tp/2
```
- **γ**：振荡参数（半周期数），MP(2003) 对 165 条记录标定 γ ~ N(1.8, 0.4)、左截断于 1。
  **默认 1.8，UI 中 NFP 下可调（1–3）**。γ=1 为单周期脉冲。
- **加速度**：用上式的**解析导数**（非数值微分）：
  ```
  a(t) = −(A/2)·[ ω_e·sin(ω_e·τ)·cos(ω_c·τ+φ) + ω_c·(1+cos(ω_e·τ))·sin(ω_c·τ+φ) ]
  其中 ω_c = 2π/Tp，ω_e = 2π/(γ·Tp)，τ = t−t₀
  ```
  解析式与数值微分一致到 0.02%。

**脉冲幅值 A（即 PGV）**（Bray, Rodriguez-Marek & Gillie 2009 原式）：
```
ln(PGV) = a + b·Mw + c·ln(R² + d²)          # PGV 单位 cm/s，R 单位 km
```
| 场地（Vs30） | a | b | c | d |
|---|---|---|---|---|
| 岩石 Vs30 ≥ 760 | 1.86 | 0.55 | −0.39 | 5.00 |
| 土 Vs30 < 760 | 2.11 | 0.55 | −0.39 | 5.00 |

> **注**：B-RM 关系表明前方向性脉冲对走滑/倾滑断层均发生，**PGV 不含断层类型项**，
> 故 SeisWave 不对 A 做断层修正（场地按 Vs30 区分岩/土）。
> 算例：Mw7 R5km 岩石 → PGV ≈ 66 cm/s、土 → 84 cm/s；Mw7.5 R3km 岩石 → 100 cm/s。

**信号长度约束**：脉冲有效持时 = γ·Tp，必须完整容纳于信号内；若 `n·dt < γ·Tp`
生成器报错并提示所需最小点数，杜绝脉冲被静默截断。

### 4.4 残余分解（NFP）

`core/residual.py::ResidualSpectrum`，SRSS 分解：
```
S_res = sqrt(S_total² − S_pulse²)
```
- 脉冲谱若在某周期点超过总目标谱，按安全系数整体缩小脉冲（只缩不放）；
- 残余分量用谱匹配引擎拟合至 `S_res`，叠加得总波；
- 用简化 Baker (2007) 检测确认残余分量**无脉冲**特征。

> **已知近似**：SRSS 假设脉冲与残余不相关，实际二者时域重叠，故叠加总谱有 ~10–30%
> 固有误差（震级越大、γ 越大越显著）。此为该方法固有特性，非实现缺陷。

### 4.5 脉冲识别（Baker 2007）

`core/pulse.py::BakerPulseDetector`，简化版 Baker (2007) 小波识别：PGV 门槛 +
速度小波能量占比，输出 has_pulse / confidence / pulse_period。
